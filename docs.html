Every creator is a coin.

What views is, exactly what pays whom, and the readers this site runs on. Nothing on the site is typed in by hand — every number comes from X, Blockscout or Dexscreener at load time.

The rule

  1. One coin per creator. The first Pons V2 launch on a handle, launched with the views vault as creatorFeeRecipient, is that creator's coin.
  2. Every trade pays the Pons 1% fee. 70% is the creator side; on a views coin that goes to the vault (0.5% of volume) and the launcher (0.2%). 30% (0.3%) goes to Pons.
  3. Each coin registers one X post. Its view count is what X shows, read by /api/tweet. A deleted post scores zero.
  4. Every Sunday 00:00 UTC the vault pays that week's most-watched creator's holders, pro rata by balance at the snapshot, in USDG.
  5. The creator can claim the vault's share of their own coin any time by replying to the coin's registered post with their claim code (below). Until then it accrues to the vault.

The money, in one breath

$100,000 of trading on a creator coin in a day = $1,000 of fees = $500 to the vault, $200 to the launcher, $300 to Pons. The vault only ever holds fee income; it never buys or sells anything.

feeIncome24h   = volume.h24 × 0.007        # creator side of the 1% fee
vaultIncome24h = volume.h24 × 0.005
holderYield    = feeIncome24h × 365 ÷ marketCap   # shown on the board as %

Launching

Go to ponsvault.com/launch, paste the description the launch form generates, set the creator fee recipient to the vault address, launch. Pons gives the creator no allocation — if you want a reserve, buy on the curve in the launch transaction. Then paste the CA in "Already launched?" on the site; verified coins are added to coins.json by hand within the hour.

Claim code

Deterministic, so anyone can check it. FNV-1a over the creator handle (lowercase) and the coin address, base36, upper, 7 characters.

function claimCode(handle, ca){
  let h = 0x811c9dc5 >>> 0;
  for (const ch of (handle.toLowerCase() + ':' + ca.toLowerCase())) { h ^= ch.charCodeAt(0); h = Math.imul(h, 0x01000193) >>> 0; }
  return h.toString(36).toUpperCase().padStart(7, '0').slice(-7);
}

Registry

coins.json — one entry per creator. ca stays empty until a coin is verified on chain; post is the registered X post id.

{ "handle": "MrBeast", "ca": "0x…", "post": "1234567890123456789", "added": "2026-09-14" }

Readers

Three serverless functions. Each has a try button that runs live.

routesourcereturns
/api/handle?h=FxTwitter → X syndication fallbackname, followers, verified, avatar, exists
/api/tweet?id=FxTwitter (views) → syndication fallbackauthor, text, views, likes, reposts, url
/api/coin?ca=Blockscout + Dexscreenerholders, supply, price, mcap, volume24, feeIncome24, holderYield







Not on chain yet


The vault contract is not deployed. Until it is, the fee recipient on any views coin is a plain wallet published here the day it exists, with every payout tx listed under it. Nothing on this page claims otherwise.
